# Arsenal (plugin ChellesArmes)

`creer_materiau_lueur.py` : à lancer **une seule fois** dans Unreal (Fichier > Exécuter un script Python).
Il crée `/Game/ChellesArsenal/M_LueurChelles`, un matériau qui brille : lames de sabre et traits du blaster
lumineux. Sans lui, l'arsenal marche quand même (couleurs simples + lumière).

Pour la version empaquetée du jeu (démo / jeu complet), ajouter le dossier `/Game/ChellesArsenal`
dans Paramètres du projet > Packaging > « Additional Asset Directories to Cook ».
