# CHELLES 3D

Reconstitution en 3D de mon quartier à Chelles, réalisée avec **Unreal Engine 4.27**.

## Ouvrir le projet

1. Installer Unreal Engine 4.27 et [Git LFS](https://git-lfs.com).
2. Cloner le dépôt : `git clone https://github.com/CISC077/CHELLES-3D.git`
3. Dans le dossier cloné : `git lfs pull`
4. Double-cliquer sur le fichier `.uproject`.

Les dossiers `Binaries`, `Intermediate`, `Saved` et `DerivedDataCache` ne sont pas versionnés : Unreal les recrée tout seul.
