# ChellesPhoto : le MODE PHOTO de CHELLES 3D (26/11/2026)

**Touche F12** (à changer dans OPTIONS > CONTRÔLES, ligne MODE PHOTO).

- En SOLO, le monde se fige (zombies, voitures, passants, particules). En multijoueur, le monde continue : seule ta caméra se libère.
- La caméra part de ta vue et se déplace librement (60 m autour de toi au maximum, réglable).
- La photo est enregistrée **sans l'interface** en PNG dans `Documents\CHELLES 3D - Photos`.
- Cadre TikTok 9:16 (touche T) : la photo est recadrée à la verticale, prête pour TikTok.

| Touche | Action |
|---|---|
| Clic gauche / Entrée | Prendre la photo |
| Z Q S D / flèches | Déplacer la caméra |
| Espace / C | Monter / descendre |
| Souris | Regarder |
| Maj / Alt | Plus vite / plus lent |
| Molette | Zoom |
| Clic droit + molette | Pencher la caméra |
| F | Filtre suivant (Normal, Noir et blanc, Sépia, Cinéma, Couleurs vives, Été à Chelles, Nuit bleue) |
| B | Flou de fond (net au centre) |
| T | Cadre TikTok 9:16 |
| G | Grille des tiers |
| X | Cacher / montrer mon perso |
| R | Remettre la caméra au départ |
| O | Ouvrir le dossier des photos |
| H | Cacher l'aide |
| F12 / Échap | Quitter le mode photo |

Réglages : `Photo.txt` (Bloc-notes, pas besoin de recompiler).
Console (touche ²) : `Chelles.Photo` entre ou sort du mode photo.
Journal : lignes `[Photo]` dans `Saved\Logs\FPS_Chelles.log`.
